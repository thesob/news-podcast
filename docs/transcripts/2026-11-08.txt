[EN]
Claude Code's don't-ask-again toggle quietly leaked thousands of secrets.

[EN]
Security firm Apiiro found that when developers click "yes, and don't ask again" in the AI coding tool, the exact shell command — secrets included — gets saved to a project file that nothing flags as private, so it often ends up committed to GitHub. Scanning 104,185 public copies of that file, researchers found 2,539 real secrets across 1,994 repositories and 63 organizations: database passwords, cloud service keys, SSH logins, GitHub and npm tokens, AWS keys and private keys. Their advice is blunt — untrack the file, rotate every exposed credential, and approve command patterns rather than literal commands with secrets baked in. It's a clean illustration of how a convenience toggle in an AI agent can become an organization-wide liability.

[EN]
Sources: Apiiro, via Hacker News.
